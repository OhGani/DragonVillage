# textures/ — 블록 그림 폴더

여기 있는 PNG 가 게임 속 블록 겉면이 된다. **아들이 그림을 그려 넣는 곳.**

## 규칙

- 크기 **16×16** 픽셀, PNG. (다른 크기는 16×16 으로 줄여서 쓰니까 흐려진다)
- 파일 이름 = `data/blocks.json` 의 `texture` 값. 예: `"texture": "stone"` → `stone.png`
- 윗면·옆면·아랫면이 다르면 `textureTop` / `textureSide` / `textureBottom` 에 각각 이름을 적고 파일도 3개.
- 투명한 부분은 알파(투명도)로. 나뭇잎·유리처럼 구멍이 있는 그림은 완전 투명(0) / 완전 불투명(255)만 쓰는 게 깨끗하다.
- 이름이 틀리거나 파일이 없으면 게임에서 **자홍색·검정 체크무늬**로 나온다. 그러면 이름을 확인!
- 파일을 넣고 브라우저를 새로고침하면 바로 보인다.

## 지금 있는 그림

`pnpm textures` 로 만든 임시 그림 44장. 아무 그림이나 덮어써도 된다.
임시 그림을 다시 만들고 싶으면 `pnpm textures --force` (아들이 그린 파일도 같은 이름이면 덮어쓰니 주의 — 먼저 백업).

## 그리기 도구

- 무료: [Piskel](https://www.piskelapp.com/) (브라우저), Aseprite(유료), 폰 앱 "Pixel Studio" 등
- 내보낼 때 16×16, PNG, 배경 투명 옵션 확인
