# 경험치 시스템 — 마인크래프트 방식

아들이 "전부 모으면 300 경험치"를 요청했고, 아빠가 마인크래프트 경험치 시스템 도입을 결정했다(2026-09-12). 마인크래프트의 **수치와 감각**(초록 구슬, 초록 바, 레벨 숫자, 딩 소리)을 그대로 가져오고, **쓰는 곳**만 이 게임에 맞춘다. 정본은 `data/xp.json`.

## 원칙과의 관계

- 경험치는 **플레이어 개인** 것(아빠·아들 각자). 마을 공유가 아니다.
- **할 일과 절대 연결하지 않는다.** 할 일 → 시간만. 경험치는 게임 안 행동으로만 얻는다.
- 경험치는 **쌓이는 것 + 쓰는 것**이다. 쓰는 것은 마인크래프트 인챈트처럼 "레벨을 소모"한다. 이건 "성장은 쌓이기만 한다" 원칙과 충돌하지 않는다 — 쓴 만큼 드래곤이 생기니까.
- 죽음 페널티는 마인크래프트 규칙을 따르되(구슬 드롭, 회수 가능) 값을 JSON으로 빼서 아들과 조정한다.

## 레벨 공식 (마인크래프트 Java 그대로)

다음 레벨까지 필요한 경험치 (현재 레벨 L):

| 레벨 구간 | 다음 레벨까지 |
|---|---|
| 0–15 | 2L + 7 |
| 16–30 | 5L − 38 |
| 31+ | 9L − 158 |

누적 경험치 → 레벨 L에 도달하기까지 총량:

| L | 총 경험치 |
|---|---|
| ≤ 16 | L² + 6L |
| 17–31 | 2.5L² − 40.5L + 360 |
| ≥ 32 | 4.5L² − 162.5L + 2220 |

참고값: 레벨 5 = 55, 레벨 10 = 160, 레벨 15 = 315, 레벨 20 = 550, 레벨 30 = 1,395.
`shared/rules/xp.ts`에 `xpToNextLevel(L)`, `totalXpForLevel(L)`, `levelFromTotalXp(xp)` 순수 함수 + vitest(위 참고값으로 검증).

## 쓰는 곳

### 1. 드래곤 알 부화 — 레벨 소모 (v1, 핵심)
마인크래프트 인챈트처럼 **레벨을 지불**한다. 알을 둥지에 놓고 부화 버튼 → 필요 레벨 이상이면 그 레벨만큼 차감되고 아기 드래곤이 나온다.

| 티어 | 부화 비용(레벨) |
|---|---|
| 1–3 (나무·대지·철) | 1 |
| 4 (케이크) | 2 |
| 5–7 (금·다이아·네더라이트) | 3 |
| 8–11 (화염·아이스·워터·타임) | 5 |
| 12–14 (텔레포트·치유·어스퀘이크) | 8 |
| 15 (폭발) | 10 |
| 16 (엔더) | 15 |

체감: 원정 1판에 대략 40–60 경험치(광석 10개 + 몹 4–5마리). 레벨 5 = 55 경험치 ≈ 1판, 레벨 15 = 315 ≈ 6판. 아들이 정한 "약한 것 1–2판 / 중간 3–5판 / 최강 6–8판"과 맞물린다. 부족하면 재료가 다 있어도 알 상태로 둥지에 보관된다 — 잃지 않는다.

### 2. 꾸미기 해제 — 레벨 도달 (v1)
레벨 5 모자 · 10 망토 · 20 파티클 · 30 칭호 "베테랑". 도달하면 해제, 소모 없음.

### 3. 인챈트 테이블 · 모루 (v1.1)
마인크래프트처럼 도구·안장 인챈트(효율, 내구성, 드래곤 안장 "빠른 비행"). 마을 건물로 추가. v1에는 넣지 않는다.

## 죽음

마인크래프트 규칙: 죽으면 `7 × 레벨`(최대 100) 경험치를 구슬로 떨어뜨리고 레벨은 0이 된다. 구슬은 **그 자리에서 회수 가능**.
- 원정지에서 죽음 → 포탈 앞 리스폰, 구슬은 죽은 자리에. 원정 시간 안에 가면 되찾는다. 원정 종료 시 소멸.
- 마을에서 죽음(낙하 등) → 구슬은 마을에 남아 영구 회수 가능.
- `xp.json`의 `death.dropsXp: true`. 아들이 너무 가혹하다고 하면 `false`(경험치 유지)로 바꾼다 — 이건 아들 결정 항목.

## 감각 (마인크래프트 그대로)
- 초록 구슬이 튀어나와 플레이어에게 날아온다(클라이언트 연출, 서버는 수치만).
- 핫바 위 **초록 경험치 바** + 중앙 레벨 숫자. 바는 `현재 레벨 진행도 / 다음 레벨 필요량`.
- 구슬 흡수 시 "딩" 소리, 음높이가 무작위로 조금씩 다름(마인크래프트의 그 소리 느낌).
- 레벨업 시 짧은 상승 효과음.

## 서버·프로토콜·저장

- 경험치는 **서버 권위**. 클라는 연출만.
- `players.xp_total INTEGER` (누적 경험치 정수 — 소수 제련값은 누적 후 버림). 레벨은 파생값.
- 프로토콜 추가: `0x52 XpGained` S→C `{ u16 amount, u8 sourceKind, f32 x,y,z }` (구슬 연출 위치), `0x53 XpState` S→C `{ u32 total, u8 level, f32 progress }` (재접속·정정용), `0x54 HatchReq` C→S `{ u8 dragonId }`, `0x55 HatchResult` S→C `{ u8 dragonId, u8 ok, u8 reason }`.
- 죽음 시 서버가 `XpOrb` 엔티티 생성(위치, 양, 소멸 시각) → 회수 시 `XpGained`.
- vitest: 레벨 공식 참고값, 부화 차감(레벨 단위), 죽음 드롭 상한 100, 원정 종료 시 구슬 소멸.
