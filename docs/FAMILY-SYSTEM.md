# 가족 연결 — 계정 · 할 일 · 시간 규칙

게임 바깥에 부모가 관리하는 얇은 층. **시간만** 건드리고 **아이템은 절대** 건드리지 않는다.

## 계정 세 종류

| 종류 | 로그인 | 플레이 | 시간 규칙 | 권한 |
|---|---|---|---|---|
| **부모** | 이메일 + 비밀번호 | 예 — 플레이어 프로필 자동 생성 | 없음 (선택: "아빠도 규칙 지키기" 토글로 자기 제한 가능) | 가족 관리, 할 일, 승인, 규칙, 모든 마을 관리자, 원정 시작·취소 |
| **아이** | 가족 코드 + PIN 4자리 (PWA는 로그인 유지) | 예 | 적용 | 마을 호스트(자기 마을), 원정 시작 |
| **친구(게스트)** | 닉네임 + PIN 4자리 + 마을 코드 (첫 입장 때 PIN 을 정함, PWA는 로그인 유지) | 예 | 없음 | 일반 플레이어 |

- 부모는 여러 명 가능(엄마도 승인).
- 아이는 이름·이메일·생년월일을 받지 않는다. 닉네임과 PIN만.
- **친구도 닉네임 + PIN 으로 이어한다**(아빠 결정 2026-09-19, #63): 브라우저를 바꾸거나 저장소가 지워져도 이름 + PIN 을 넣으면 같은 플레이어(토큰 복원). 닉네임은 서버 전체에서 하나만 — 이미 있는 이름이면 "이 이름은 있어요. 네 것이면 PIN 을 넣어" 로 이어하기, 아니면 다른 이름. PIN 5번 틀리면 10분 잠금. 아이 = 친구와 같은 닉네임 + PIN 에 가족 연결(가족 코드)만 더한 것. 개인 정보는 여전히 받지 않는다.
- 부모 플레이어의 진행(드래곤·도감·꾸미기)은 부모 것. 마을·창고는 공유. 부모 → 아이 드래곤 양도 불가.

## 시간 모델

```
오늘 쓸 수 있는 시간 = 기본 시간(요일별) + 오늘 얻은 보너스 + 수동 조정
오늘 얻은 보너스   = min( 오늘의 보너스 한도, round(오늘 승인된 할 일 수 / 오늘 할 일 수 × 오늘의 보너스 한도) )
오늘의 보너스 한도 = 지난주 달성률 → 구간표 (주 단위 정산, 최대 10분)
```

- **기본 시간**: 요일별. 권장 초기값 평일 20분 / 주말 40분. (20분 = 원정 1판 + 마을 정비, 보너스 10분 = 두 번째 원정 가능)
- **보너스 최대 10분/일.**
- **차감**: 서버가 접속 중 1분마다 `used_min += 1`. 마을에서 가만히 있어도 차감. 5분 무입력 → 자동 로그아웃.
- **수동 조정**: 부모가 사유와 함께 ±분. 기록은 아이 화면에도 보인다.
- **기본 시간은 서버 로직이 절대 깎지 않는다.**

### 주간 정산 — 지난주가 이번 주를 정한다 (확정)

매주 **월요일 00:00 Asia/Seoul**, 지난주(월–일) 할 일 달성률 → 이번 주 매일의 보너스 한도.

| 지난주 달성률 | 이번 주 매일 한도 | 아이 화면 문구 |
|---|---|---|
| 90% 이상 | 10분 | "지난주 대단했어. 이번 주는 매일 한 판 더 열 수 있어." |
| 75–89% | 7분 | "거의 다 했어. 이번 주 조금만 더." |
| 50–74% | 4분 | "절반은 넘었어. 이번 주는 4분까지." |
| 50% 미만 | 0분 | "이번 주는 기본 시간만. 다음 주에 다시 열려." |
| 첫 주(기록 없음) | 10분 | "처음이니까 믿고 시작할게." |

- 달성률 = 지난주 승인(또는 자동 인정)된 할 일 수 / 지난주 예정된 할 일 수. 할 일이 0개면 100%.
- 구간과 분 수는 `data/family-rules.json` 기본값, 부모 화면에서 변경 가능.
- 두 단계 구조: **꾸준함은 한도로, 오늘의 노력은 즉시 보상으로** 답한다.

## 할 일

- 필드: 제목, 반복(매일 / 요일 지정 / 한 번), 승인 필요 여부, 활성.
- 상태: `pending` → 아이 체크 `checked` → 부모 `approved` / `rejected`. 승인 불필요 항목은 체크 즉시 `approved`.
- 권장: 승인 필요 항목은 하루 1–2개("수학 숙제"). "이 닦기"류는 승인 불필요.
- 승인되는 순간 보너스가 붙고 아이 화면에 "+N분" 표시.

## 접속 불가 시간대

- 요일별 `blocked_ranges` (예: 평일 `[["00:00","16:00"],["21:00","24:00"]]`).
- 차단 중 로그인 → `error BLOCKED_HOURS`, 문구 "16시에 열려요".
- 접속 중 차단 진입: 원정 출발 조건이 이를 막으므로 마을에서만 발생 → 5분 전 경고, 진입 시 `ForceReturn`.
- "오늘 게임 없음" 토글(부모): 그날 전체 차단.

## 게임과 만나는 지점

- **원정 출발 조건**: `min(남은 오늘 시간, 차단 시작까지 남은 분) ≥ 원정 길이 + 3분`. 불충족 시 포탈 문구 "오늘은 마을에서 놀자". → 시간은 항상 **마을에서** 끝난다. 부모·게스트는 이 조건 없음.
- **원정 출발 권한**: 호스트(아들) 또는 부모 계정. 아들이 시간 없음/로그아웃이면 친구들끼리 원정 불가(아빠가 있으면 가능).
- **HUD**: 아이 화면에 남은 시간 상시. 5분 전 색 변화, 1분 전 "다음에 또 봐" → 마을에서 퇴장.
- **게임 내 승인**: 부모가 플레이 중이면 `ApprovalPrompt`가 HUD 카드로 → 1탭 승인. 부모 페이지 갈 필요 없음.
- 원정 중 아이 시간 종료(출발 조건 덕에 거의 없음): 아이만 마을 복귀, 친구 파티는 계속.

## 부모 화면 `/family`

폰 브라우저에서 1분 안에 끝나야 한다.
1. **승인 대기** 맨 위. 알림 → 승인 버튼 바로.
2. **할 일 관리**: 제목, 반복, 승인 필요 여부.
3. **시간 규칙**: 요일별 기본 시간, 접속 불가 시간대, 보너스 구간표, "오늘 게임 없음".
4. **이번 주**: 달성률, 날짜별 플레이 분, 다음 주 예상 한도.
5. **수동 조정**: ±분 + 사유.
6. 알림: 웹 푸시(VAPID). PWA 설치 시 iOS·Android 모두. 미지원 환경은 페이지 배지.

## 아이 화면

- 로그인 후 마을 전 **"오늘의 할 일" 카드**: 남은 시간, 오늘 한도, 할 일 목록(체크 버튼).
- 규칙 전체 공개: 기본 시간, 오늘 한도, 지난주 달성률, 수동 조정 기록. "왜 오늘은 4분이야?"에 화면이 대답한다.

## 한계 (정직하게)

브라우저 시간 제한은 기기 수준 제한이 아니다. 다른 브라우저로 게스트 입장하면 마을 구경은 가능(원정은 못 연다). 완전 차단은 기기 스크린타임의 일이고, 이 시스템은 **약속의 기록 장치**다. 우회를 막는 기술보다 우회할 이유를 없애는 규칙(기본 시간 보장, 벌 없음, 투명한 화면)에 투자한다.

## 개인정보

- 수집: 부모 이메일, 아이 닉네임·PIN 해시, 할 일 기록, 일별 플레이 분.
- 아이 프로필은 부모가 만든다 → 만 14세 미만 법정대리인 동의 구조. 짧은 개인정보처리방침 1장.
- 시간 계산은 전부 서버, Asia/Seoul. 클라 시계는 믿지 않는다.
