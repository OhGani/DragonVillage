# 로드맵 — M0부터 공개까지 38주

주 8–10시간(평일 저녁 + 주말 반나절) 기준. 각 마일스톤 끝에 **아들이 손에 쥐고 해볼 수 있는 빌드**. 완료 기준을 만족하기 전에 다음으로 가지 않는다. 2주마다 플레이테스트 → `PLAYTEST-LOG.md`.

| M | 이름 | 기간 | 완료 기준 |
|---|---|---|---|
| **M0** | 기술 검증과 조작 실험 | 2주 | 아들이 폰·PC 양쪽에서 설명 없이 5분 안에 블록을 부수고 쌓는다. PC 60fps, 중급 폰 30fps+ |
| M1 | 월드의 뼈대 (싱글) | 4주 | 브라우저를 껐다 켜도 아들이 만든 집이 그대로 있다 (IndexedDB) |
| M2 | 멀티 코어 — 마을 | 5주 | 아빠는 PC로, 아들은 폰으로 같은 마을에 집을 짓는다. 폰을 잠갔다 켜도 그 자리 |
| M3 | 원정 루프 — 게임의 심장 | 5주 | 둘이 원정을 다녀와서 "한 번 더 갈까?"가 나온다. 원정 시간 값 확정 |
| M4 | 가방·조합·채팅 | 4주 | 아들이 JSON을 고쳐 새 레시피를 만들고, 채팅 문구 20개 확정 |
| M5 | 가족 연결 — 계정·할 일·시간 | 4주 | 아들이 할 일 체크 → 아빠가 폰(또는 게임 내 HUD)에서 승인 → 한 판 더 열린다. 월요일 정산 확인 |
| M6 | 마을 성장 + 드래곤 + 경험치 | 5주 | 2주 뒤 접속한 친구가 "마을 커졌다"고 먼저 말한다. 아들이 경험치 레벨을 써서 첫 드래곤 알을 부화시키고, 안장을 얹어 타고, 빔을 쏜다 |
| M7 | 원정의 위험 + 보스 | 4주 | 남은 3분에 "돌아가자!"가 채팅에 찍힌다. 죽으면 구슬이 떨어지고 되찾을 수 있다. 아빠와 아들이 거미 왕을 잡고, 우민 방어전을 한 번 막아낸다. 엔더 드래곤 전투 기본형 (일정 밀리면 방어전을 v1.1로) |
| M8 | 마감 | 3주 | 처음 보는 아이가 링크만 받고 30초 안에 들어와 첫 원정을 끝낸다 |
| M9 | 공개(가족·친구) | 2주 | 아들이 친구 다섯에게 코드를 보내고, 여섯 명이 함께 원정을 다녀온다 |

M5는 게임 엔진과 거의 독립적인 API·DB 작업 → 순서 조정 가능, 아빠 전문 영역이라 가장 빨리 끝날 가능성. M2·M3을 앞에 둔 것이 핵심 결정(멀티는 나중에 못 붙인다, 원정이 심장이다).
