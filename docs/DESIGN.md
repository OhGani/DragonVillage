# 게임 설계 v0.4

> 아빠가 만들고 아들이 설계하는 복셀 드래곤 원정 게임
> 웹 · 2–6인 협동 · 한 판 15분 · 영구 마을 + 일회성 원정 · 부모 시간 관리

## 1. 한 줄 정의

마인크래프트 세계를 배경으로, **15분짜리 원정을 다녀올 때마다 우리 마을이 조금씩 자라고 드래곤이 하나씩 늘어나는 게임**. 친구들과 링크 하나로 모여 한 판 다녀오고, 자연스럽게 끊고, 다음에 돌아오면 마을은 그대로 있고 더 커져 있다.

| 항목 | 값 |
|---|---|
| 플랫폼 | 웹 브라우저 — 폰(주 기기) · 태블릿 · PC |
| 한 판 | 10–20분, 원정 1회 = 세션 1회 |
| 인원 | 보통 2명(아빠·아들), 마을 하나에 최대 6명 |
| 게임 시간 | 아이: 기본 시간 + 할 일 보너스 최대 10분/일. 부모: 제한 없음 |
| 기간 | 약 38주, 주 8–10시간 |
| 공개 | 없음. 가족·친구 비공개 |

## 2. 설계 원칙

1. **한 판은 끝이 있어야 한다.** 원정에 시간 제한이 있고, 돌아오면 정산이 있고, 그 지점이 "오늘은 여기까지"다.
2. **게임 안의 성장은 쌓이기만 한다.** 원정 실패, 며칠 미접속 — 잃는 것 없음. 출석 보상, 기간 한정 이벤트 없음.
3. **할 일은 시간과만 연결된다, 아이템과는 절대 연결하지 않는다.**
4. **기본 시간은 건드리지 않는다.** 할 일 미완료 = 보너스 없음. 벌 없음. (부모 수동 조정만 예외)
5. **2주마다 아들이 실제로 플레이할 수 있어야 한다.**
6. **멀티는 처음부터, 서버가 세계의 진실이다.**
7. **친구는 링크 하나로 30초 안에 들어와야 한다.** 설치·가입·계정 없음.
8. **아들이 코드를 몰라도 게임을 바꿀 수 있어야 한다.** 데이터·텍스처·규칙은 코드 밖(`data/`).
9. **개인정보는 부모 이메일 하나 외에 0, 자유 채팅은 없다.**

## 3. 게임 구조 — 영구 마을 + 일회성 원정

세계는 두 층이다.

- **마을**: 128×128×128, 영구, 서버 저장. 친구들과 함께 짓고 절대 사라지지 않는다. 마을 건물(제작대·창고·대장간·농장·등대·포탈·드래곤 둥지)이 실제 블록 구조물로 서 있다.
- **원정지**: 256×256×128, 매번 새 시드로 생성, 원정 종료 시 폐기. **저장하지 않는다.**

### 핵심 루프

마을에 모임 → 원정 출발 → 재료·발견 → 귀환·정산 → 마을·드래곤이 자람 → 다음 판

### 15분 세션의 박자

| 시간 | 단계 | 내용 |
|---|---|---|
| 0:00–2:00 | 모이기 | 마을 접속, 어제 지은 것 구경, 오늘 원정지 고르기. 늦은 친구는 원정 중 합류 가능 |
| 2:00–12:00 | 원정 | 포탈로 새 지형 도착. 10분 동안 낮→밤 한 사이클. 재료 채집, 보물 구조물 탐색, 밤이 깊어지면 위험 |
| 12:00–13:00 | 귀환 | 포탈 닫히기 전 복귀. 못 돌아오면 가방의 절반만 가져옴 |
| 13:00–17:00 | 정산·건설 | 전리품 정리, 도감 등록, 드래곤 부화/제작, 마을 건물 짓기. 자연스러운 종료 지점 |

원정 시간은 `data/expeditions.json`의 값. 10분이 맞는지는 M3 플레이테스트에서 아들이 확정.

### 무엇이 자라는가

| 성장 축 | 어떻게 보이나 | 무엇으로 |
|---|---|---|
| **드래곤** (핵심) | 드래곤 도감. 약한 것부터 센 것까지 티어. 마을 둥지에 산다 | 원정지에서 모은 재료 조합 |
| 마을 건물 | 제작대→창고→대장간→농장→등대→포탈 확장→둥지. 눈에 띄게 커짐 | 원정 자원 (`buildings.json`) |
| 원정지 해제 | 초원 섬→동굴·사막→설원→네더→엔드. 포탈 단계마다 새 지형·재료·위험 | 포탈 건물 단계 |
| 도구 티어 | 나무→돌→철→금→다이아→네더라이트(곡괭이 6종 = 어스퀘이크 드래곤 재료). 채굴 속도, 파낼 수 있는 블록 | 대장간 + 광석 |

| **경험치·레벨** (개인) | 마인크래프트식 초록 바 + 레벨 숫자. 초록 구슬, 딩 소리 | 채굴·몹·제련·귀환·도감 (`xp.json`). 알 부화에 레벨 소모 → `XP-SYSTEM.md` |
| 내 캐릭터 | 색·모자·망토·파티클·칭호 해제. 능력치 없음 | 레벨 5/10/20/30 도달, 도감 달성, 드래곤 16종 완성("드래곤 마스터") |

**규칙**
- 재료를 다 모으면 **알**이 나오고 알에서 **아기 드래곤**이 나온다. 만들 때 쓴 재료를 먹이면 더 빨리 자란다. **어른이 되면 약 2배 크기, 더 무섭게**(긴 뿔·척추 가시·이빨 줄·큰 날개·긴 꼬리·빛나는 눈) — 스킬 위력·기력·HP도 오른다. 복셀 모델은 `models/`에 아기·어른 두 단계.
- **안장**을 만들면 어느 드래곤이든 탈 수 있다. **고유 스킬 16종 전부 확정**(아들 2차 답변) — 공통 기본 공격 5종(꼬리치기·깨물기·머리 박치기·내리치기·몸통 박치기) + 드래곤별 빔(색·세기) + 고유 스킬 1~6개. 아군 피해 없음이 전역 규칙. → `DRAGON-SKILLS.md`, `dragons.json`
- **죽을 수는 있지만 도망치지 않고, 얻으면 영원히 내 것.** 구현: 죽으면 둥지로 돌아가 회복(원정 1회 출전 불가) — 아빠 확정 필요.
- 드래곤은 **개인 소유**(아빠·아들 각자). 마을 **둥지**는 공유 건물, 3단계로 커진다(4→10→16마리).
- 폰 탑승 조작: 조이스틱 이동, 점프 = 상승, 웅크리기 = 하강. 타고 걸을 수 있지만 몸집이 커서 장애물에 잘 걸린다(의도).
- **알 부화에는 경험치 레벨을 소모한다**(마인크래프트 인챈트 방식, 티어 1→1레벨 … 티어 16→15레벨). 레벨이 모자라면 알은 둥지에 보관. 전부 모으면 300 경험치 + "드래곤 마스터" 칭호(아들 요청). → `XP-SYSTEM.md`
- 6명: v1 협동 재료 모으기 + 엔더 드래곤 협동 전투. 드래곤 대결·경주는 v1.1.

**원정지 6곳** (재료 출처에서 역산, `expeditions.json`): 초원 섬(포탈 1) · 동굴 · 사막(포탈 2) · 설원(포탈 3) · 네더(포탈 4) · 엔드(포탈 5, 15분). 보스 설계로 추가된 4곳(어두운 숲·정글·깊은 어둠·고대성)은 v1.1/v1.2.

### 보스와 마을 방어전 (아들 설계, 2026-09-12)

정본 `data/bosses.json`, 상세 `BOSSES.md`. **"모두 우리 마을을 차지하고 싶어한다"** — 이 한 줄이 마을을 키우고 드래곤을 모으는 이유를 준다.

> 마을을 노리는 왕들이 있다. 원정에서 재료를 모아 드래곤을 키우고, 드래곤과 함께 마을을 지키고, 마지막에는 고대성으로 가서 네 왕을 물리친다.

| 보스 | 사는 곳 | 버전 |
|---|---|---|
| 거미 왕 (왕관, 독, 거미 군단) | 동굴 | **v1** |
| 소환사 — 우민들 (벡스 군단, 파괴수 기병, 불사의 토템) | 마을 옆 전초기지 → **마을 방어전** / 삼림 대저택 | **v1** / v1.1 |
| 엔더 드래곤 (숨결 바닥 + 엔더맨) | 엔드 | **v1** |
| 초거대 가스트 (큰 화염, 거대 네더 요새) | 네더 | v1.1 |
| 거대 워든 (음파, 내리치기, 워든 군대) | 깊은 어둠 · 고대 도시 | v1.2 |
| 거대 고릴라 (고릴라 군단, 정글 궁궐, 분노) | 정글 | v1.2 |
| 네 왕 — 거대 스켈레톤·크리퍼·엔더맨·좀비 왕 (고대성, 목표: 서버 지배) | 고대성 | v1.2 = **엔딩** |

**마을 방어전**: 호스트가 시작하는 10분·3웨이브 세션. 시간 규칙·원정 출발 조건 동일 적용, 자동 시작 없음. 마을은 서버가 원상복구(잃는 것 없음). 실패하면 보스 깃발이 입구에 꽂히고, 승리하면 "수호자" 깃발로 바뀐다. 보스 전투는 리스폰 무한, 전리품 전원 동일, 드래곤 탑승 전투.

**보물 상자에는 드래곤 재료만** 들어 있다. 캐기·몹 처치·거래 전부 허용. 가스트의 눈물·엔더 드래곤의 알은 처치 필수, 블레이즈 막대·엔더 진주·위더 스켈레톤 머리는 확률 드롭. 드래곤의 숨결은 엔더 드래곤의 바닥 공격을 유리병으로 담는다(처치 불필요).

## 5. 조작 — 폰 우선, PC 동급 지원

아들의 주 기기는 **폰**. M0에서 폰·PC 양쪽 검증.

**폰·태블릿**
- 왼손 **고정 스틱**(왼쪽 아래, 항상 보임, 그 자리에서만 — 아들 7차 피드백으로 '엄지 닿은 곳에 생성'에서 변경, 결정 #54), 그 밖의 곳 드래그 시점. 좌우 회전이 상하보다 빠름
- 짧은 탭 = 놓기, 길게 = 부수기(홀드 게이지). 중앙 십자선 + 조준 블록 외곽선
- 원정 타이머 화면 상단 중앙 상시 표시, 남은 3분부터 색 변화
- `touch-action: none`, 전체화면 API, 가로 모드 안내, `100dvh`
- PWA "홈 화면에 추가"
- 드래곤 탑승: 조이스틱 이동, 점프 버튼 = 상승, 웅크리기(▼) 버튼 = 하강. 탑승 중 히트박스가 커서 장애물에 걸림(아들 의도)

**PC**
- Pointer Lock, WASD, Space 점프, 1–9 슬롯, E 가방, Tab 도감
- 좌클릭 부수기(홀드), 우클릭 놓기

**게임패드**: Gamepad API

**M0 합격 기준**: 아들이 설명 없이 폰과 PC 양쪽에서 5분 안에 블록을 부수고 쌓는다.

## 6. 멀티플레이 요약

(상세: `ARCHITECTURE.md`, `PROTOCOL.md`)

- 호스트(아들)가 마을 생성 → 6자리 코드. 친구는 링크 → 닉네임·색 → 코드 → 30초 내 입장.
- 서버 권위: 블록 변경 검증(도달 5블록, 보호 구역, 초당 상한), 위치 20Hz + 100ms 보간, 지형은 시드 공유·diff만 전송, 타이머·정산·자원·도감 전부 서버 계산.
- 공유 창고 하나. 개인 기여도 표 없음(초5 여섯 명에게 싸움의 씨앗).
- 재접속: `localStorage` 세션 토큰. 원정 중 끊겨도 타이머 안이면 복귀.
- 호스트·부모 권한: 킥, 보호 구역, 원정 시작·취소. 마을 건물은 자동 보호. 개인 집터는 표지판으로 보호 지정.
- 원정 출발 권한: 호스트(아들) 또는 부모 계정.
- 안전: 자유 채팅 없음, 닉네임 필터, 코드 브루트포스 IP 제한, 공개 목록 없음.

## 7. 협업 — 아들이 게임을 바꾸는 통로
