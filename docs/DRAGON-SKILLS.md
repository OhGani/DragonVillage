## 아들 설계에서 읽어낸 세 가지 규칙

1. **빔은 공통 시스템이다.** 16종 중 14종이 "○○색 ○○한 빔"을 갖는다. 색과 세기만 다르다 → 빔 하나를 잘 만들고 색·세기를 데이터로 뺀다. 세기 표현을 숫자로: 약한 1 · 약간 센 2 · 강한/강력한 3 · 매우 강력한 4 · 가장 강력한 5. 피해 = 4 × 세기.
2. **아군에게는 절대 피해가 없다.** 아들이 스킬마다 "자신이나 주인, 동료들은 피해가 없음"을 반복해서 적었다 → 스킬별 옵션이 아니라 **전역 규칙**(`combat.friendlyFire: false`). 회오리·쓰나미·낙하물·폭발 전부 포함. 초5 여섯 명 협동에서 이게 없으면 싸움 난다.
3. **스킬은 유형이 몇 개 안 된다.** 52개 스킬이 전부 아래 12개 유형으로 환원된다. 유형별로 한 번 구현하면 나머지는 데이터.

| 유형 | 뜻 | 예 |
|---|---|---|
| `melee` | 근접 기본 공격 | 꼬리치기, 깨물기 |
| `beam` | 직선 광선, 색·세기 | 모든 빔, 눈 레이저, 힐 케이크 빔(target: allies) |
| `projectile` | 날리기 | 철·금·다이아·네더라이트 블록, 케이크, 얼음, 물 |
| `projectile_burst` | 여러 개 동시 | 곡괭이 6종 날리기 |
| `falling_blocks` | 하늘에서 떨어지기 | 흙·돌, 모루, 네더라이트 비 |
| `aoe_rain` | 범위에 비처럼 | 불 비, 보라색 에너지 볼 |
| `aoe_spin` | 회오리(몸 회전) | 다이아 회오리, 보라색 회오리 |
| `cone` / `aura` / `wave` | 부채꼴 / 몸 주변 지속 / 전진 파도 | 불 뿜기 / 불 두르기 / 쓰나미 |
| `summon` / `summon_aoe` | 소환 | 엔더맨 군대 / 물 회오리 |
| `heal` / `shield` | 아군 회복 / 방어막 | 치유 드래곤 |
| `utility` | 세계·위치 조작 | 나무 세우기, 벽 세우기, 블록 녹이기·얼리기, 5×5 채굴, 텔레포트 |
| `global_freeze` | 시간 멈추기 | 타임 드래곤 (적만 30초 정지) |

## 전투 모델

- **기력(stamina)** 100, 초당 5 회복. 스킬마다 소모(15~80). 강한 스킬은 쿨타임도 길다(2초~120초). 숫자는 아빠 임시값, 아들이 `dragons.json`에서 바꾼다.
- **폰 탑승 UI**: 화면 오른쪽에 스킬 버튼 **최대 4개** + 기력 바. 기본 공격 5종은 탭 공격 시 상황에 맞게 자동 선택(가까우면 깨물기, 여럿이면 내리치기, 돌진 중이면 몸통 박치기) — 버튼을 차지하지 않는다.
- **서버 권위**: 스킬 발동 요청 → 서버가 기력·쿨타임·사거리 검증 → 효과 계산 → 브로드캐스트. 클라는 연출. 채굴·블록 변환 스킬(5×5 캐기, 녹이기, 얼리기, 벽 세우기)은 서버 블록 변경 검증에서 **드래곤 스킬 예외**(도달 거리 무시)를 두되 보호 구역은 여전히 막는다.
- **타임 드래곤 시간 멈추기** (아들 확정): 서버가 적대 엔티티 전부에 30초 `frozen` 플래그. **원정 타이머는 멈추지 않는다.**
- **시간 되돌리기** (아들 확정): **플레이어들과 이 드래곤을 제외한 모든 것을 10초 전으로 되돌린다. 위치 포함. 원정 타이머는 제외.** 즉 적·몹·보스·투사체가 10초 전 자리와 HP로 돌아가고, 적이 부순 블록이 복구된다. 플레이어와 드래곤은 지금 자리에 그대로 — 보스 앞까지 달려간 뒤 보스만 되감아 뒤에서 치는 식의 플레이가 나온다. 구현: 서버가 적 상태와 적 블록 변경을 1초 간격 링버퍼로 10초 보관, 발동 시 되감고 스냅샷 브로드캐스트. 동료 드래곤도 제외(아빠 해석), 플레이어가 놓은 블록은 그대로.

## 버전 배치

- **v1 (M6·M7)**: 기본 공격 5종, 빔, 드래곤별 대표 스킬 1개(`signature: true`) — 16종 × (5 + 1 + 1). 대표 스킬은 아들 목록에서 가장 그 드래곤다운 것을 골랐다(화염 = 불 뿜기, 아이스 = 얼음 쏘기, 타임 = 시간 멈추기, 어스퀘이크 = 5×5 캐기, 엔더 = 숨결 뿌리기 …). 아들이 다른 걸 대표로 바꿔도 된다.
- **v1.1**: 나머지 스킬 전부 — 시간 되돌리기, 쓰나미, 엔더맨 군대, 방어막, 네더라이트 비, 자폭 등.
