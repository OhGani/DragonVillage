## 2026-09-13 — M0 비공식 플레이테스트 (아들 폰, GitHub Pages 배포본)

설명 없이 5분 관찰은 아직. 아빠가 아들 옆에서 해보며 받은 피드백과 반영.

| 아들 피드백 (그대로) | 반영 | 커밋 |
|---|---|---|
| 전체화면으로 실행이 안 됨, 전체화면/해제 버튼이 있었으면 | 켜기/끄기 토글 버튼, 아이폰은 홈 화면 추가 안내 + 매니페스트 | `ad7159e` |
| 안내 페이지 닫힘 버튼이 안 먹음 | 클래스 충돌·hidden 우선순위 수정 | `d72aa05` |
| 아이템 창이랑 들고 있는 블록이 겹침 | 손 블록을 화면 모서리에 고정 | `79e5769` |
| 앞으로 갈 때 한 칸 높은 블록은 그냥 올라갔으면 | 자동 턱 오르기 | `b5c305e` |
| 물·용암은 벽이 없으면 같은 높이까지 채워져야 | 마인크래프트 규칙 액체 시뮬 | `56171e2` |
| 물을 설치한 방향으로만 흐르게 (용암도) | 놓은 방향으로만 흐르는 원천 | `ff4e2d8` |
| 조이스틱 한 곳에 표시해 두고 그 자리에서만 | 왼쪽 아래 고정 스틱 | `34352bd` |
| 좌우로 화면 돌리는 속도 높이기 | 가로 감도 1.7배 | `34352bd` |
| (아빠) 동서남북이 어딘지 모르겠어 | 위 가운데 나침반(보는 방향이 맨 위, 북 빨강, 8방위 글자) | `4c18228` |
| (아빠) 물길에 빠지니까 나올 방법이 없음 | 물속 둑 오르기(1.3칸)·둑을 밀면 떠오르기·얕은 물 진짜 점프 | `+process.argv[1]+` |

관찰: 아들이 조작·물리·액체 같은 "마인크래프트와 다른 점"을 정확히 짚어낸다. 폰 FPS 수치는 아직 못 받음 → 다음에 `i` 버튼 값 기록.
