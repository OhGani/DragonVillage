## 2026-09-19 — M2 실접속 (아빠 PC + 아들 폰, 서버 http://115.68.221.179:5173)

**결과: M2 완료 기준 셋 다 통과.** 서로 보임 / 블록 동기화 / 폰 잠갔다 켜도 같은 자리 (아빠 확인).

**발견 — 같은 폰에서 다른 브라우저(또는 새 창)로 같은 이름을 쓰면 플레이어가 2명 생긴다.**
- 원인: 지금 "나"는 이름이 아니라 **브라우저에 저장된 토큰**(`localStorage dv.token`)이다. 브라우저가 다르면 저장소가 달라 새 토큰 = 새 플레이어. 같은 브라우저의 새 탭은 같은 토큰이라 옛 연결이 끊기고(4001) 한 명만 남는다. 이름은 머리 위 표시일 뿐 검사하지 않는다.
- 아빠 질문: 나중에 가방·드래곤이 생기면 이렇게 갈라진 플레이어의 아이템은 어떻게 되나 → 서버 DB 는 토큰 기준(`players.token`)이라 **없어지진 않지만 다른 브라우저에서는 못 꺼낸다**. 브라우저 데이터를 지우거나 폰을 바꾸면 같은 문제. 아이폰 사파리는 7일 안 쓴 사이트의 저장소를 지우기도 한다(홈 화면에 추가한 웹앱은 예외).
- 답: 가족 계정(M5, 가족 코드 + PIN)이 이 문제의 정식 해법 — 로그인하면 어느 기기든 같은 플레이어. 친구(게스트)는 설계상 계정이 없으니 기기를 바꾸면 새 플레이어(허용). M4 가방이 M5 보다 먼저라 **아들 계정만큼은 M4 전에 PIN 로그인을 앞당기는 것**을 검토. 추가로 서버가 **접속 중인 같은 이름을 거절**("이 이름은 지금 마을에 있어요")하면 실수로 둘이 되는 일은 막을 수 있다.
- **아빠 결정(2026-09-19)**: 원래 계획대로 M5 에서 하되, **친구도 계정을 유지** — 모든 플레이어 닉네임 + PIN 4자리로 이어하기(결정 #63). 아빠가 아들 질문 3개(레드스톤 첫 작품 / 마을 TNT / 발광석 가루 개수)와 묘목 1 vs 2 를 직접 확인하기로.
